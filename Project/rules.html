Rules & Levels

Basic Rules

  • As an optional Mens Gymnast meaning over level 7 this means you are able to create your routine and add whatever skill you want with having to follow a couple of guidelines.
  • Each event has element groups that must be satisfied in order to get the full credit for the routine. There are 4 for each of the 6 event and there is many options to choice for each one.
  • Each completed element group with the required difficulty level will give you .5 to your starting value. If all of the element groups are satisfied then your starting base score will be a 12.0

The Level System

There is 10 levels starting with 4 and usually going up 1 level per year on average and doing 3 years of level 10

Level Description
4-7 These are called the compulsory levels where each gymnast is compting the same set routine but may add bonus skills to get a higher score
8-10 These are known as the optional level where the gymnast is allow to make there own routines while following certain requirements and guidelines
